# Playtest Log

*Owner: Gio. The class asks for peer playtesting. This file is the evidence, so keep it honest and specific.*

## How to run a session

1. Give the tester the JAR (or the laptop). Say only: "This is a game. Try to survive."
2. **Don't explain** the controls unless they are stuck for over a minute. If they get stuck, that's a finding.
3. Watch quietly. Write down what they do, not what they say they'll do.
4. Ask the questions at the bottom afterward.
5. Fill in one row per tester, and one row per issue.

## Questions to ask each tester

1. In one sentence, what is the goal of the game?
2. What was the most fun moment?
3. What was confusing or frustrating?
4. Was it too easy, too hard, or fine? Which night felt different?
5. Could you tell what the lighthouse beam does? When did you figure it out?
6. Was there any moment you wanted to quit?
7. Would you play again? What would you change first?
